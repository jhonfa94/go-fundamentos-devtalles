# Comandos

## Iniciar modo

```
go mod init hello_world
```

## Ejecutar programa en go (El main.go hace referencia al main del proyecto)
```
go run main.go
```

## Crear ejecutable
Debemos estar en el path del proyecto 
```
go build
```

## Crear ejecutable con otro nombre
Despues del -o indicamos como queremos que se llame
```
go build -o hello
```

## Ejecutar binario de go
```
./hello_world
```


## Fromatear el código desde la terminal 
Debemos estar en la ruta del proyecto
```
go fmt ./...
```


### Verificar el estado de los archivos del proyecto
```
go vet ./...
```
